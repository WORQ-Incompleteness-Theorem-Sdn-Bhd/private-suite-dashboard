💡 Quick Tips

  • • Each room/suite must have a unique id attribute in the SVG
  • • Use consistent naming conventions for room IDs (e.g., "room-101", "suite-202")
  • • Export SVGs with optimized settings to reduce file size
  • • Test your floorplan after uploading to ensure all rooms are clickable
  • • Use the drag-and-drop feature to reorder floorplans as needed
